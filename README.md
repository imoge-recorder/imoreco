PC版 Google AI Studio 向けの非公式 Chrome / Edge ブラウザ拡張機能です。  
ご自由にご利用ください。基本的に最新版をダウンロードしていただければ動作します。

アップローダーサービス「getuploader.com」の終了に伴い、従来の配布場所（`https://uu.getuploader.com/imoreco/`）からこちらのGitHubへ移行いたしました。  
今後は本ページにて最新版の配布・更新を行います。

---

## ダウンロード方法

1. このページの右側（スマートフォンの場合はページ下部）にある **[Releases]** をクリックします。
2. 最新のリリース（例: `Imoge Recorder for AI Studio`）を開きます。
3. **Assets** の一覧にある **`Imoge.Recorder.for.AI.Studio.x.x.x.zip`** をクリックすると、ダウンロードが開始されます。

> **※注意**  
> 「Source code (zip)」ではなく、ファイル名にバージョン番号が入った **拡張機能本体の zip ファイル** をダウンロードしてください。
